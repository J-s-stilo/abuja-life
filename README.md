# ABUJA LIFE

ABUJA LIFE is an original browser-based virtual life and city simulation game.

Players can create a virtual life in Abuja, earn fictional in-game money, work jobs, own properties and vehicles, interact with other players, make friends, chat, and build their virtual lives.

## Virtual Economy

Every new player starts with ₦1,000,000 in fictional in-game currency.

The currency has no real-world cash value and cannot be withdrawn.
